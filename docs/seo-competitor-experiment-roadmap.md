# 바로계산 경쟁 서비스 반영 실험 로드맵

작성일: 2026-08-17

## 운영 원칙

- 한 번에 하나의 가설만 적용한다.
- 각 변경은 작고 되돌릴 수 있게 만든다.
- 바로 앞 변경으로부터 최소 7일이 지나기 전에는 다음 화면 변경을 겹치지 않는다.
- Search Console 데이터가 적으면 28일 누적값과 절대 클릭 수를 함께 본다.
- 검색 노출만을 위한 대량 페이지, 자동 클릭, 링크 스팸은 사용하지 않는다.
- 사이트맵과 색인 요청을 반복 제출하지 않는다.

## 현재 기준선

- Search Console 최근 28일: 클릭 2, 노출 52, CTR 3.8%, 평균 게재순위 15
- 색인됨 6페이지, 색인되지 않음 15페이지
- 사이트맵: 성공, 발견된 URL 26개
- `84-square-meter-to-pyeong` 가이드: 노출 22, 클릭 0
- 연봉·영문 주소·면적·환율 핵심 페이지: 모두 색인됨, 클릭 0
- GA4 최근 28일: 활성 사용자 3, 세션 3, 자연 검색 세션 0

## 2026-08-17 통합 적용 기록

사용자 요청에 따라 후속 전략을 별도 배포로 나누지 않고 한 번에 구현했다. 따라서 다음 효과 검토에서는 개별 변경의 인과관계를 단정하지 않고 통합 적용 전후의 페이지별 지표를 비교한다.

- 평수: 84㎡ 기본값, 59·74·84·102·114㎡ 빠른 선택, 검색 제목과 가이드 강화
- 연봉: 국민연금 2026년 7월 상·하한 반영, 대표 연봉 버튼, 공식 기준 링크와 확인일 표시
- 영문 주소: 예시 검색, 건물명·지번·우편번호 구분, 주소 비저장 안내
- 환율: 달러·엔화·유로·위안 인기 통화쌍과 대표 금액 버튼
- 측정: `calculator_use`, `calculator_preset`, `address_search`, `result_copy`

다음 검토는 최소 7일 뒤 실시하며, 낮은 기준선에서는 비율보다 첫 비브랜드 클릭, 페이지별 노출 절대값과 행동 이벤트 발생 여부를 우선 판단한다.

## Cycle 1 — 기술 구조화 데이터

가설: 계산기 페이지의 잘못된 BreadcrumbList를 수정하면 페이지 이해와 색인 안정성이 개선된다.

- 상태: Phase A 완료, 측정 중
- 변경: URL이 없는 중간 카테고리 breadcrumb 제거
- Phase B 최초 검토 가능일: 2026-08-24
- 성공 기준: 구조화 데이터 오류 재발 없음, 색인 수 유지 또는 증가, 핵심 URL 정상 응답

## Cycle 2 — 84㎡·평수 검색 의도

가설: `84㎡ 몇 평` 검색자가 원하는 값과 입력 상태를 첫 화면에서 즉시 제공하면 CTR과 계산기 이용이 증가한다.

계획된 변경:

- 면적 계산기의 기본 방향을 `㎡ → 평`으로 변경
- 59·74·84·102·114㎡ 빠른 선택 버튼 추가
- 84㎡ 가이드에서 계산기를 열 때 84㎡가 미리 입력되도록 연결
- 가이드 제목 후보: `84㎡ 몇 평? 25.4평과 34평형의 차이`
- 전용면적·공급면적 비교를 짧은 표로 제공

성공 기준:

- 28일 노출 22 → 28 이상 또는 첫 비브랜드 클릭 발생
- 해당 페이지 CTR 0% → 2% 이상
- 평균 게재순위 2단계 이상 개선
- 계산 완료 이벤트를 추가한 경우 유입 대비 완료율 측정 가능

## Cycle 3 — 연봉 계산 신뢰성

가설: 공식 근거와 계산 조건을 명확히 표시하면 급여 검색에서 신뢰도와 이용 완료율이 높아진다.

계획된 변경:

- 2026년 적용 기준과 최종 갱신일 표시
- 국민연금·건강보험·국세청 간이세액표 등 공식 출처 연결
- 현재 예상 소득세 방식과 간이세액표의 차이를 검증
- 필요 시 20세 이하 자녀 수 입력을 부양가족 수와 분리
- 3천·4천·5천·6천·8천·1억 원 빠른 선택 버튼 검토

성공 기준:

- 연봉 페이지 노출 25% 이상 증가 또는 첫 자연 검색 클릭 발생
- 계산 완료율 및 결과 복사율 측정 가능
- 계산 근거와 실제 급여 차이에 대한 안내가 결과 가까이에 표시됨

## Cycle 4 — 영문 주소 완료율

가설: 예시 검색과 결과 구분 정보를 강화하면 사용자가 올바른 주소를 선택하고 복사하는 비율이 증가한다.

계획된 변경:

- 세종대로 110, 테헤란로 152, 아파트 주소 예시 버튼
- 중복 결과에 건물명·지번·우편번호를 함께 표시
- 전체 주소와 Address Line 1/2 등 항목별 복사 동작 점검
- 공식 주소 데이터 출처와 개인정보 처리 안내를 결과 가까이에 표시

성공 기준:

- 주소 페이지 첫 자연 검색 클릭 발생 또는 노출 25% 이상 증가
- 검색 성공 대비 전체 주소/항목별 복사율 측정 가능
- 같은 검색어의 복수 결과를 사용자가 구분할 수 있음

## Cycle 5 — 환율 롱테일 의도

가설: 인기 통화와 대표 금액, 기준일과 수수료 차이를 첫 화면에서 명확히 보여주면 일반 환율 검색보다 구체적인 이용 의도를 확보할 수 있다.

계획된 변경:

- USD·JPY·EUR·CNY 인기 통화 버튼
- 10·100·1,000 등 대표 금액 버튼
- 기준환율 출처와 기준일 표시 유지 및 가독성 강화
- 실제 카드·은행 적용환율과의 차이를 결과 가까이에 표시
- Search Console 수요가 확인된 통화쌍만 별도 콘텐츠 후보로 선정

성공 기준:

- 환율 페이지 첫 자연 검색 클릭 발생 또는 노출 25% 이상 증가
- 통화 변경 및 계산 완료 행동 측정 가능
- 자동 생성한 얇은 통화쌍 페이지 없이 구체 검색어 노출 증가

## 피드백 규칙

- 개선: 변경을 유지하고 다음 Cycle로 이동한다.
- 불변: 같은 화면에 추가 변경을 겹치지 않고 제목 또는 사용 흐름 중 하나만 수정한다.
- 악화: 원인이 명확하고 되돌리기가 안전할 때만 해당 Cycle 변경을 최소 롤백한다.
- 판단 유보: 데이터가 7일 미만이거나 노출이 너무 적으면 같은 Phase를 유지한다.
