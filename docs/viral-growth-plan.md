# 바로계산 30일 바이럴·검색 유입 실행안

## 목표

- 검색에서 필요한 순간 바로 발견되는 계산기 사이트로 자리 잡는다.
- 사용자가 계산을 마친 직후 친구·동료에게 공유하는 흐름을 만든다.
- 광고비 없이 검색, 유용한 콘텐츠, 자연스러운 입소문을 중심으로 초기 방문자를 확보한다.

## 이번 배포에 반영한 성장 장치

1. 모든 계산기 페이지에 모바일 공유 및 링크 복사 버튼을 배치한다.
2. 공유 링크에 UTM 값을 넣어 향후 채널별 유입과 공유 성과를 측정할 수 있게 한다.
3. GA4가 연결되면 권장 이벤트인 `share`가 자동 기록되도록 준비한다.
4. 페이지마다 고유 제목, 설명, 키워드, Open Graph 정보를 제공한다.
5. 계산기와 이동 경로를 설명하는 WebApplication·Breadcrumb 구조화 데이터를 제공한다.
6. 각 계산기에 실제 사용자가 묻는 질문과 답변을 추가해 검색 의도를 넓게 충족한다.
7. 카카오톡과 SNS 링크 미리보기용 이미지를 클릭 유도형 메시지로 개선한다.

## 핵심 성장 루프

검색 질문 → 정확한 계산 결과 → 관련 도구 탐색 → 공유 버튼 → 새 방문자 → 다시 검색·공유

공유를 강요하거나 보상을 미끼로 쓰지 않는다. 결과가 유용한 순간에만 한 번 자연스럽게 제안한다.

## 30일 운영 일정

### 1주차: 검색 기반 완성

- Google Search Console에서 사이트맵과 주요 URL 색인을 확인한다.
- 네이버 서치어드바이저에 `barocalc.co.kr`을 등록하고 `sitemap.xml`을 제출한다.
- Google Analytics 4 속성을 연결하고 `share`, `search`, `select_content` 이벤트를 확인한다.
- 우선 홍보 대상은 연봉 실수령액, 영문 주소, 환율, 평수 변환 네 페이지로 제한한다.

### 2주차: 문제 해결형 콘텐츠 배포

- 네이버 블로그 또는 운영자 블로그에 아래 주제로 원문 4개를 발행한다.
  - 2026년 연봉 5천만 원 실수령액과 공제항목
  - 해외 배송 영문 주소 입력란별 작성법
  - 84㎡는 몇 평인가: 전용면적과 공급면적 차이
  - 카드 해외결제 전 환율 계산 시 놓치기 쉬운 수수료
- 각 글은 답을 본문에서 충분히 설명한 뒤 관련 계산기 한 곳만 자연스럽게 연결한다.

### 3주차: 커뮤니티 검증

- 질문이 실제로 올라온 게시물에만 답변하고, 계산 과정과 주의사항을 먼저 제공한다.
- 동일 문구를 여러 커뮤니티에 반복 게시하지 않는다.
- 반응이 좋은 질문과 표현을 사이트 FAQ와 검색 키워드에 반영한다.

### 4주차: 성과 기반 확장

- Search Console에서 노출은 높지만 클릭률이 낮은 페이지의 제목과 설명을 한 번만 개선한다.
- 공유 클릭이 많은 계산기 3개를 랜딩 페이지 상단 인기 태그에 유지한다.
- 검색 노출이 전혀 없는 도구는 사용 예시와 FAQ를 보강한다.
- 다음 달 콘텐츠는 실제 검색어와 공유 데이터로 결정한다.

## 채널별 바로 게시 가능한 문안

### Threads·X

연봉 실수령액, 영문 주소, 환율, 평수처럼 자주 찾지만 매번 검색하게 되는 계산기를 한곳에 모았습니다. 가입 없이 모바일에서 바로 사용할 수 있어요. https://barocalc.co.kr

### 네이버 블로그 소개문

연봉 협상 전 실수령액을 확인하거나 해외 배송용 영문 주소가 필요할 때 여러 사이트를 돌아다니지 않도록 생활 계산 도구를 한곳에 정리했습니다. 입력값은 저장하지 않으며 모바일에서도 바로 사용할 수 있습니다. 필요한 계산기는 바로계산에서 검색해 보세요: https://barocalc.co.kr

### 지인·직장 동료 공유

연봉 실수령액이나 평수, 환율 계산할 때 쓰기 편한 사이트라 공유해요. 가입 없이 바로 됩니다. https://barocalc.co.kr

### 영문 주소 콘텐츠용 문안

해외 직구나 국제우편에서 Address line 1, City, State를 어떻게 나눠야 하는지 헷갈릴 때가 많습니다. 한글 도로명주소를 검색하면 영문 주소와 우편번호를 입력란별로 정리해 줍니다. https://barocalc.co.kr/life/address

## 매주 확인할 지표

- Search Console: 검색 노출수, 클릭수, 평균 CTR, 상위 검색어
- GA4 연결 후: 계산기별 방문수, 공유 이벤트 수, 내부 도구 이동수
- 1차 판단 기준: 공유 버튼 클릭률 2% 이상, 검색 CTR 3% 이상
- 절대 방문자 수보다 어떤 계산기와 검색어가 반복적으로 방문·공유를 만드는지 우선 본다.

## 운영 원칙

- 가짜 후기, 자동 댓글, 무관한 커뮤니티 도배, 링크 구매는 하지 않는다.
- 세금·급여·환율 정보의 기준일과 한계를 명시한다.
- 광고는 핵심 계산과 결과를 가리지 않도록 배치한다.
- 제목과 설명을 단기간에 반복 변경하지 않고 최소 2~4주 단위로 평가한다.
